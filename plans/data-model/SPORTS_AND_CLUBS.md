# Sports Teams and Clubs

## Sports team

Fields:

- id;
- name;
- organization;
- sport vocabulary reference;
- level/category;
- gender/category as locally and lawfully published;
- season;
- league/conference;
- home facilities;
- coaches/advisors only when publicly listed;
- schedule resource;
- results feed alternate optional;
- eligibility policy link;
- registration/tryout information;
- contact;
- status;
- images/brand;
- provenance.

The standard should allow jurisdiction-neutral classifications and namespaced values.

## Sports event

Use the general event model with:

- home/away participants;
- venue;
- competition;
- result only if the publisher chooses;
- ticket link;
- status/cancellation;
- accessibility.

Real-time scores are optional and likely belong in a specialized adapter.

## Club

Fields:

- id;
- name;
- description;
- organization/department;
- category;
- advisor role/person;
- student leadership must not include private student information; public student names are discouraged in core EOM;
- meeting schedule;
- location;
- eligibility;
- fees;
- application/join link;
- contact;
- status/effective period;
- public website/social links.

## Student privacy

Core recommendation:

- do not publish student-member rosters;
- do not publish student officers by default;
- if a school publicly publishes student leadership under lawful policy, use an extension or future reviewed profile rather than encouraging it in the core.

## Website use

Generate:

- athletics directory;
- team pages;
- activity directory;
- calendar filters;
- tryout and club fair listings.
