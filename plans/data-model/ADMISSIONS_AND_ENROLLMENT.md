# Admissions and Public Enrollment Information

## Scope

Public process information, not applicant or student records.

## Admissions profile

Fields:

- id;
- organization/program scope;
- admissions type;
- audience/education levels;
- overview;
- eligibility criteria;
- application windows;
- deadlines;
- required public documents;
- fees;
- application URL;
- open house/events;
- selection/lottery policy link;
- catchment/attendance area link;
- contact;
- languages;
- accessibility/accommodations contact;
- status/effective period;
- provenance.

## Enrollment facts

Allowed:

- published aggregate enrollment;
- capacity category;
- accepting applications status;
- year/term;
- observation date;
- source.

Not allowed:

- applicant identities;
- application status;
- individual waitlist position;
- student records;
- immigration/medical/private details.

## Availability

A public `acceptingApplications` field should include:

- value;
- for which level/program;
- observedAt;
- expires;
- application link;
- disclaimer.

## Catchment

Link to a boundary resource or authoritative government GIS source. Include effective dates and “verify with organization” notice.

## Website use

Generate:

- admissions overview;
- steps;
- deadlines;
- required documents checklist;
- open house events;
- application buttons;
- catchment map integration.
