# Public Data Governance Method

## Data lifecycle

```text
identify authority
→ inventory sources
→ classify fields
→ extract/author
→ validate
→ review
→ publish
→ observe
→ correct
→ supersede/archive
```

## Governance dimensions

- ownership;
- publication authority;
- provenance;
- effective dates;
- quality;
- privacy;
- licensing;
- correction;
- retention;
- historical continuity.

## Data quality dimensions

- completeness relative to declared profile;
- validity;
- consistency;
- uniqueness;
- timeliness;
- provenance coverage;
- semantic accuracy;
- accessibility;
- localization coverage.

Schema validity is only one dimension.

## Review frequency

Set at module/resource level based on volatility and risk. Use automated reminders but require accountable owners.

## Corrections

Corrections should preserve:

- previous observation;
- reason;
- source;
- effective date;
- review decision;
- public correction time.

Urgent privacy removal may redact first and complete history review afterward.

## Foundation index governance

Future index data must distinguish:

- origin claim;
- government claim;
- vendor claim;
- derived normalization;
- inferred match;
- reviewer resolution.

The index should expose correction and opt-out processes, source dates, and limitations.
