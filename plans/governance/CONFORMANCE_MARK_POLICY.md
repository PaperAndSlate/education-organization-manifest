# Conformance Mark Policy Plan

## Objective

Allow accurate interoperability claims without suggesting factual endorsement.

## Mark levels

Potential:

- EOM Core Publisher;
- EOM School Publisher;
- EOM Course Catalog;
- EOM Signed Publisher;
- EOM Consumer;
- EOM Validator.

## Requirements

- current passing conformance report;
- profile and version named;
- report URL;
- no unresolved critical failures;
- periodic retest for hosted endpoints;
- mark removed when materially nonconforming.

## Required disclaimer

Conformance means format/protocol behavior passed the named suite. It does not verify school quality, accreditation, ratings, data truth, legal compliance, or paper&slate endorsement.

## Visual use

- do not alter mark;
- do not place in misleading review/rating context;
- do not use on unrelated products;
- accessible alt text;
- version visible in accompanying text.

## Enforcement

- correction notice;
- grace period;
- mark revocation;
- public invalid-claim record only when necessary and fair;
- appeal process.

## Open standard protection

Implementations can conform without using the mark.
