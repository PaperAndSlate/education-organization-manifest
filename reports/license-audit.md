# License audit evidence

Repository licensing is explicit: software, schemas, tests, and tooling use Apache-2.0;
specification/documentation uses CC-BY-4.0; and marked fictional fixtures use CC0-1.0. `REUSE.toml`
records the machine-checkable mapping and every non-private workspace package declares Apache-2.0.

```powershell
pnpm license:check
```

Legal review remains an external release gate. This report is a repository metadata check, not legal
advice or approval of third-party source rights.
