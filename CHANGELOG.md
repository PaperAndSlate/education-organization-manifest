# Changelog

All notable changes to the EOM repository are documented here. This project follows a Keep a Changelog-style format and Semantic Versioning for packages and protocol artifacts.

## [Unreleased]

### Added

- Phase 0 repository charter, governance baseline, traceability matrix, and implementation scaffolding.
- Offline conformance profiles, fixture reports, and the `eom conformance` CLI command.
- Release-candidate packaging with immutable spec/schema artifacts, deterministic source archive,
  checksums, CycloneDX SBOM, and local provenance metadata.
- Offline lint, security, license, dependency, release, and generated-drift gates.

### Status

- The `educational-organization-manifest` well-known suffix remains a proposed working selection and is not claimed as IANA-registered.
- Independent interoperability, legal review, stable governance approval, and production deployment remain external gates.
