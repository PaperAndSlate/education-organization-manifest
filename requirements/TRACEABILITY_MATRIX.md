# EOM Requirement Traceability Matrix

This matrix is the living bridge between the approved planning pack and the repository. Rows are
atomic acceptance units rather than broad feature claims. `open` means implementation or evidence is
still incomplete; `verified-local` requires a direct executable check; `blocked-external` is reserved
for actions outside the repository. No row uses a local test to claim registration, legal approval,
independent adoption, certification, or deployment.
