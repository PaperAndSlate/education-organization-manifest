# Governance Baseline

The repository follows the approved RFC and ADR processes in `plans/governance/`. Protocol semantics, schema changes, new modules, conformance profiles, signatures, versioning, and registry submissions require an RFC. Implementation architecture requires an ADR. Each accepted change links a requirement, compatibility classification, tests, documentation, privacy/security review, and migration note where relevant.

The initial steward is paper&slate. The project is deliberately neutral: the steward does not become the authority for any school's published facts. Maintainers should grow representation from schools, districts, vendors, developers, privacy/security, accessibility, and international education as adoption develops.
