# Project Status

EOM is a working-draft protocol and reference implementation. The proposed `educational-organization-manifest` suffix is not claimed as IANA-registered. General production guidance is gated on the registration process, security/privacy review, public review, and interoperability evidence described in `spec/1.0/iana-registration.md` and `reports/release-checklist.md`.

The repository provides local schemas, validation, generation, conformance, documentation, release-candidate artifacts, and fictional fixtures. A passing local test or signature proves format/integrity behavior only; it does not prove that an organization's facts are true, current, lawful, or endorsed by paper&slate.

External work that cannot be completed from this checkout—such as IANA acceptance, legal review, independent pilot participation, and third-party certification—is tracked as an explicit blocker with the evidence required to close it in `release/external-gates.md` and `reports/external-gates.md`.
