# RFCs

RFCs are required for core fields, modules, profiles, semantic meaning, signatures/security, versioning, IANA/media/link registration, governance, and breaking API/schema changes. A proposal records motivation, use cases, non-goals, data/protocol behavior, compatibility/migration, privacy/security, internationalization/accessibility, provenance, conformance, implementation, and decision status.

The proposed well-known suffix and media/link strategy are tracked in `spec/1.0/iana-registration.md` and remain subject to public review and the applicable registry process.
