# Educational Organization Manifest Specification

EOM is a proposed open protocol stewarded by paper&slate. The versioned specification and schemas are designed for independent implementation. The current repository status is working draft; the proposed `educational-organization-manifest` well-known suffix is not claimed as IANA-registered.
