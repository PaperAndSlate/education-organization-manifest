# ADR-0003: Canonical JSON Wire Format with YAML Authoring

- Status: Accepted
- Date: 2026-08-25
- Related requirements: EOM-GEN-001, EOM-SIG-001

## Decision

Publish canonical UTF-8 JSON. Permit safe YAML/JSON authoring source that is normalized into the canonical model; never sign source YAML. Canonical serialization follows RFC 8785-compatible rules.

## Consequences

Human source stays readable while consumers receive stable bytes. Duplicate keys, unsafe YAML features, and ambiguous dates are rejected.

## Validation

Two clean builds compare byte-for-byte and signature fixtures use canonical generated bytes.
