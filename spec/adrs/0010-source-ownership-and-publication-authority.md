# ADR-0010: Separate Source Ownership from Publication Authority

- Status: Accepted
- Date: 2026-08-25
- Related requirements: EOM-OWN-001, EOM-AGENT-001

## Decision

CODEOWNERS and review matrices govern authoring source edits. The root origin governs public authority and can explicitly delegate a resource scope to a vendor or district. Agents create candidates; publication remains a human-approved release action.

## Consequences

Department autonomy does not grant root authority, and a vendor is not mistaken for the school. Review and provenance metadata remain auditable.

## Validation

Ownership/delegation fixtures, generated review reports, candidate publication gate tests, and phase release checks.
