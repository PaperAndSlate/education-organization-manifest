# Interoperability fixtures

These files are intentionally small, local, and fictitious. They contain public descriptive metadata only and use reserved `example` domains. No adapter test fetches a URL, executes markup, opens an archive, or includes a person-level record.

`prohibited-input.json` is the one boundary fixture with a prohibited field name. Its value is only a redaction marker; it exists to prove that the adapter quarantines the shape before copying any data.
