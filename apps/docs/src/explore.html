What to inspect

  1. Compare the compact root with its linked organization and module resources.
  2. Open the course catalog and observe durable course definitions separated from offerings and sections.
  3. Inspect localized values, effective dates, role contacts, provenance, and aggregate statistics.
  4. Evaluate district transport and vendor meals only through their explicit delegation records.
  5. Run the conformance command and read the report without interpreting it as school endorsement.
Why the example is safe to copy

Every factual value is synthetic, every host is an example domain, and the repository’s tests reject the privacy and authority failure fixtures. Replace the identifiers, ownership, and review evidence before using the shape for a real organization.

The example demonstrates format behavior, not a real school or production deployment.
