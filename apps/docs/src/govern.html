Govern

Keep the draft honest

EOM is designed for independent implementations and public review. paper&slate stewards the repository; it does not own a school’s facts or become the authority merely by providing tools.

Status language

  • Say proposed well-known URI suffix until external registration is accepted.
  • Say working draft for the current specification and release candidate.
  • Say tested against EOM 1.0 [profile] for a named local test result.
  • Do not claim IANA acceptance, independent pilot adoption, 1EdTech certification, school endorsement, factual truth, or production readiness without recorded evidence.

Change control

Normative protocol changes belong in versioned specifications and RFCs. Architecture choices are recorded in ADRs. Schemas are structural source of truth; generated types and schema docs are rebuilt and drift-checked. Security and privacy reports should be reproducible and should distinguish repository evidence from external review.

External gates

Gate Repository can prepare Still external
Well-known registration Submission draft, rationale, expert questions IANA registry decision
