# EOM Governance

paper&slate is the initial steward and change controller for the neutral Educational Organization Manifest. Stewardship does not give paper&slate ownership of facts published by schools, districts, vendors, or other organizations.

Maintainers oversee repository health and releases. Specification editors oversee normative prose, schemas, compatibility, and RFC decisions. Security contacts coordinate private vulnerability response. Community reviewers contribute expertise in schools, international education, privacy, accessibility, interoperability, and implementation.

Editorial changes need maintainer review. Implementation changes use code review and an ADR when architectural. Compatible protocol changes require an RFC, tests, documentation, and migration analysis. Breaking changes require a major-version RFC, interoperability evidence, and formal approval. Security emergencies may receive a narrow patch followed by a public retrospective where safe.

Prefer rough consensus with documented rationale and dissent. Governance cannot override the privacy boundary, silently change a released schema, or claim IANA registration, adoption, certification, legal approval, or factual verification without evidence.

See `spec/rfcs/`, `spec/adrs/`, `docs/governance/`, and `plans/governance/` for the processes and templates.
