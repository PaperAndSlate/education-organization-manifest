# Ecme High authoring source

This directory is the checked-in YAML input for the deterministic reference build. The source is intentionally synthetic and contains no student records, private staff data, credentials, private schedules, individual transport assignments, or security-sensitive facility details.

`eom.config.yaml` owns publication settings. Each module file contains either an authoring object or an EOM-compatible `items` collection. Source ownership is represented by the example CODEOWNERS template; generated files under `../generated/` are never edited by hand.
