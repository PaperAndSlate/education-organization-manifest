# Code of Conduct

EOM follows the Contributor Covenant Code of Conduct. Participants are expected to be welcoming, respectful, specific, and attentive to the different legal, educational, linguistic, accessibility, privacy, and cultural contexts in which the protocol may be used.

Harassment, discrimination, intimidation, doxxing, malicious disclosure, and attempts to bypass the project's privacy or security boundaries are not acceptable. Report concerns privately to the maintainers or the security contact. Maintainers will review reports fairly, protect confidentiality where possible, and document enforcement decisions without exposing unnecessary personal information.
