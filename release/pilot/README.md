# Independent interoperability pilot packet

This packet is ready for an independent publisher and consumer, but no participant or exchange is
claimed. Use fictional `.example` fixtures only, keep logs free of personal or student data, and
record the exact EOM profile, fixture digest, implementation versions, and observed HTTP behavior.

The packet closes only when two independently operated implementations exchange the same fixture
and the coordinator archives redacted evidence. A local Ecme report is not independent evidence.
