# EOM 1.0 licensing

The repository uses machine-readable licensing metadata through `REUSE.toml`:

- software, schemas, generated types, tests, and tooling: Apache-2.0;
- specification and documentation: CC-BY-4.0;
- marked fictional examples and fixtures: CC0-1.0.

Third-party source content must not be copied into a publication or fixture without a compatible
right to use it. A source inventory records rights and transformation metadata for approved evidence;
an adapter may map structured public facts only through its documented allowlist. The release
license check verifies workspace package declarations and required REUSE identifiers, but legal
review remains an external gate.
