# EOM 1.0 Module Registry

The module registry records a stable module URI, resource type, schema/version, privacy class, freshness guidance, collection behavior, conformance profile, mappings, owner, and review date. All modules are optional unless a named profile requires one. Core modules include organization, campus, departments, staff/contacts, courses, offerings/sections, programs, calendars/events, facilities/services/policies, admissions, sports, transportation, meals, clubs, jobs, news, statistics, and APIs.

Every module has structural and semantic tests, a valid fixture, principal invalid fixture(s), authoring/generator support, documentation, Ecme coverage, mapping notes, and privacy/security review. Unknown open vocabulary values are preserved; closed safety-critical values fail.
