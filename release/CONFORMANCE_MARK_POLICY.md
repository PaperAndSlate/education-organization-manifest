# Conformance mark policy

The repository does not grant a certification mark. An implementation may describe a local result
only as “tested against EOM 1.0 `<profile URI>`” when it links to a current machine-readable report
and names the implementation version and fixture set.

The phrase must not imply factual verification, accreditation, legal compliance, privacy approval,
security certification, IANA registration, paper&slate endorsement, or interoperability with an
independent implementation. A report status of `partial` or `non-conforming` must be shown as such.
External use of branding, badges, or certification language requires a future governance decision.
